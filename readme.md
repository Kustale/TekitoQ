* 구축 방법

1. 웹 서버에다 파일들을 그대로 올린다(폴더 하나 만들고 올려도 된다. 안에 폴더 내용 바꾸면 안된다)
2. 만약 리눅스 서버라면 올린 폴더에다 권한을 주거나 data폴더 하나 만들어서 권한을 준다(chmod -r 1777 .)
안주면 가입이고 뭐고 안된다. 오류가 왕창 뜬다(data폴더 만들어도 안에 생성을 못한다)
3. 처음 구동이 될경우 data폴더가 생성이 된다. 중요하니까 지우면 안된다(생성이 됬다는 뭐가 뜨면 F5를 누르던 뒤로를 누르던...)
(모르고 지웠다가 내 계정 날라갔니 마니 하면 곤란하다)
4. 모든 소스는 지식 없이는 섣불리 수정해서는 안된다.
실수로 소스 하나라도 삭제되면 기능이 죄다 맛이간다
게임이 맛이 가면 그게 게임인가
수정은 유니코드 편집기로 한다(리눅스는 거의 지원, 윈도우 라면 Notepad++ 추천)
5. 계정은 data/user폴더에 들어간다. 이벤트라고 뭐 하나 끼워주고 싶으면 이걸 열어서 수정해준다
단, 왼만하면 지식이 있어야 하며 유니코드 지원되는 편집기로 열어야 된다. 메모장으로 열면 순식간에 폭파된다
(리눅스는 거의 유니코드 지원한다. 윈도우라면 Notepad++를 추천한다)
로그인도 안되고 데이터 개판 치기 싫다면...

자세한건 있는 지식으로 소스 훑어보고 깨우치면 된다.
